# DK Bicicleta Elétrica — conceito de experiência

Protótipo responsivo com três direções de apresentação selecionáveis: escolha guiada, comparação e loja & cuidado. O estudo complementa os canais oficiais já existentes e liga à loja atual, páginas de produto e WhatsApp.

## Rodar localmente
Abra `dist/index.html` em um navegador.

## Publicação
GitHub Pages publica a pasta `dist/` pelo workflow incluso.

## Fontes e limites
- Site e endereço: https://dkbicicletaeletrica.com.br/
- Catálogo de produtos: páginas oficiais linkadas nas fichas.
